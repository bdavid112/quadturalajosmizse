# QuadTuraLajosmizse 🏍️

A fully custom, full-stack web application built for an ATV tour company based in Lajosmizse, Hungary. The project features multilingual support, a mobile-first responsive design, a custom admin dashboard, and user authentication — all built from scratch using modern web technologies.

---

## ✨ Features

- 🌐 **Multilingual interface** (e.g. Hungarian and English)
- 📱 **Fully responsive UI** optimized for mobile and desktop
- 🔐 **User authentication** with secure session handling
- ⚙️ **Admin dashboard** for managing bookings, tours, and content
- 📅 **Booking functionality** with form validation
- 📦 **Built with a modular, component-based structure**

---

## 🛠️ Tech Stack

**Frontend:**
- React
- SCSS (modular styling)
- 

**Backend:**
- Node.js + Express
- MongoDB (with Mongoose)
- AdminJS (admin interface)
- Express-session + middleware-based auth

**Other Tools:**
- Git & GitHub for version control
- Figma (UI planning)
- Postman (API testing)
